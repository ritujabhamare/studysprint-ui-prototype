# StudySprint — Student Study Planner

StudySprint is a simple, responsive study-planning web prototype that helps students organize tasks and track their daily progress.

## Features
- Add new study tasks.
- Mark tasks as complete or incomplete.
- Automatically update total tasks, completed tasks, and progress percentage.
- Responsive layout for desktop and mobile screens.
- Built with HTML, CSS, and vanilla JavaScript.

## How to run
1. Download or clone this repository.
2. Open `index.html` in Chrome, Firefox, or another web browser.
3. Add a task and click the check button to test the dynamic progress tracker.

No installation or build tools are required.
